# Reporting security problems

Do not publish gRPC tokens, endpoint registrations, credentials or private application data in issues, pull requests or logs. Kasane connects to local emulators using their existing authentication and does not require exposing them over the network.

For a suspected vulnerability, contact the repository owner Armando Picón (@devpicon) privately through an existing agreed channel before sharing details. No support SLA or coordinated disclosure program is established for this preview.
